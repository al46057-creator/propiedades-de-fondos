VIDEOJUEGOS Y TECNOLOGÍA

1. Fondos planos o colores sólidos

Los fondos planos utilizan un solo color. En CSS podemos definirlos con nombres de colores, códigos HEX, RGB o RGBA.

Color HEX

Propiedad: background-color

background-color: #7c3aed

Este color morado se define mediante un código hexadecimal.

Color RGB

Propiedad: background-color

background-color: rgb(0, 217, 255);

RGB combina rojo, verde y azul para formar un color.

Color RGBA

Propiedad: background-color

background-color: rgba(255, 0, 110, 0.6);

RGBA permite controlar la transparencia mediante el valor alfa.

2. Fondos con degradados o gradientes

Los degradados mezclan dos o más colores de manera gradual. Se crean con funciones como linear-gradient() y radial-gradient().

Degradado lineal

Propiedad: background-image

background-image: linear-gradient(90deg, #7c3aed, #00d9ff);

Los colores se mezclan siguiendo una dirección.

Degradado radial

Propiedad: background-image

background-image: radial-gradient(circle, #00d9ff, #17132e);

Los colores se distribuyen desde un punto central hacia afuera.

3. Fondos con imágenes

CSS permite colocar imágenes como fondo y controlar su repetición, posición y tamaño para mejorar la apariencia de una página.

Imagen de fondo

Propiedad: background-image

background-image: url("imagen.jpg");

Permite utilizar una imagen como fondo de un elemento.

Repetición de imagen

Propiedad: background-repeat

background-repeat: repeat;

Repite la imagen para cubrir el espacio disponible.

Posición de imagen

Propiedad: background-position

background-position: center;

Permite elegir dónde se coloca la imagen dentro del elemento.

Tamaño de imagen

Propiedad: background-size

background-size: cover;

Hace que la imagen cubra el área sin dejar espacios vacíos.

El universo gamer

Las imágenes de fondo permiten crear ambientes visuales atractivos para páginas de videojuegos y tecnología.
